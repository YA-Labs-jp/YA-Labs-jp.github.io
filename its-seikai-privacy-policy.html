IT'S正解
プライバシーポリシー

第1条（基本方針）

  1. 本プライバシーポリシー（以下「本ポリシー」といいます。）は、YA Labs.（以下「運営者」といいます。）が提供するアプリケーション「IT'S正解」（正式名称「IT'S正解 - みんなの正解を予想しろ -」。以下「本サービス」といいます。）における、利用者の個人情報、個人関連情報その他の利用者に関する情報の取扱いについて定めるものです。
  2. 運営者は、利用者のプライバシーを尊重し、個人情報の保護に関する法令その他関係法令を遵守するとともに、適切な安全管理措置を講じ、利用者に関する情報を適切に取り扱います。
  3. 本ポリシーは、本サービスの利用に関して適用され、利用規約とあわせて適用されます。
  4. 利用者は、本サービスを利用した時点で、本ポリシーに同意したものとみなします。

第2条（取得する情報）

運営者は、本サービスの提供にあたり、以下の情報を取得する場合があります。

1. 利用者が入力または送信する情報

  • プレイヤー名
  • 回答（本文、ならびに投稿および編集の日時）
  • 通報の理由（不適切な内容、誹謗中傷・攻撃的な内容、個人情報、広告・宣伝、その他。自由な文章による通報はありません）
  • お知らせを開いた日時
  • お問い合わせのメールに記載された内容

2. 認証に関する情報

本サービスでは、閲覧のための匿名認証と、Googleアカウントによるログインを利用します。

Googleアカウントによるログインでは、認証およびアカウント管理のため、Firebase Authenticationが発行する利用者固有の識別子（UID）を利用します。Android版のログインでは、メールアドレスの利用範囲を要求します。

なお、運営者は、次の情報を運営者が管理するCloud Firestoreその他のデータベースには保存しません。

  • Googleアカウントのメールアドレス
  • Googleアカウントの表示名
  • Googleアカウントのプロフィール画像

Firebase Authenticationは、Googleログインに伴い、これらの情報を認証情報として保持する場合があります。匿名の利用者についてもUIDを利用します。匿名の利用だけでは、プレイヤー名は登録しません。

3. サービスの提供に伴い保存する情報

  • 回答の集計結果、ポイント、順位およびランク
  • シーズンの成績
  • 通知設定（シーズンの開始、お題の公開、結果の確定、自己最高ランクの更新）。Webブラウザでは、現在、これらの個別設定を保存しません
  • プッシュ通知配信のためのFCMトークン。Webブラウザでは登録しません
  • 通知の履歴（タイトル、本文、種類、既読、受信日時）。対応する端末内に最大100件保存します。運営者のサーバーには保存しません

4. 自動的に取得する情報

本サービスでは、サービス提供および品質向上のため、以下の情報を取得する場合があります。

（1）Firebase Analytics

アプリが送信する記録は、次の範囲です。回答本文およびプレイヤー名は含めません。

  • アプリを開いたこと
  • Googleアカウントでログインしたこと
  • 回答を投稿または編集したこと、および対象のお題の識別子
  • 結果を閲覧したこと、対象のお題およびシーズンの識別子、ならびにその画面に表示する順位およびポイント
  • シーズンのランキングを閲覧したこと、および対象シーズンの識別子

Firebase Analyticsが上記以外に端末等から取得する情報の項目は、アプリのコードからは特定できないため、本ポリシーでは断定しません。

（2）Firebase Crashlytics

Webブラウザでは利用しません。それ以外の対応する端末では、クラッシュ情報およびエラー情報を送信する場合があります。アプリが付加する情報は、実行環境の区別と、未ログイン、匿名またはGoogleのいずれの状態かです。利用者の識別子および回答本文は付加しません。

（3）Firebase Performance Monitoring

Webブラウザでは利用しません。それ以外の対応する端末では、起動、回答の送信、結果の読み込みおよびランキングの読み込みに要した時間を計測する場合があります。計測に回答本文は含めません。

（4）Firebase Cloud Messaging

Webブラウザでは利用しません。それ以外の対応する端末では、プッシュ通知配信のためのFCMトークンを取得します。

（5）Google Mobile Ads

Android版では、バナー広告、および回答を編集する前の動画広告をリクエストする場合があります。広告のリクエストに、回答本文その他の投稿内容は含めません。Webブラウザでは広告を表示しません。広告に関するソフトウェアが端末から取得する情報の項目は、アプリのコードからは特定できないため、本ポリシーでは断定しません。広告に関する設定は、Googleアカウントまたは端末の設定から変更できる場合があります。

第3条（情報の利用目的）

運営者は、取得した情報を、次の目的のために利用します。

  1. 本サービスの提供、運営および改善のため
  2. アカウントの認証および管理のため
  3. 回答、ランキング、ポイント、ランクその他本サービスの機能を提供するため
  4. 本サービス内のお知らせ、および対応する端末へのプッシュ通知の配信のため
  5. 不正利用の検知、防止、通報への対応および調査のため
  6. 利用状況の分析ならびにサービス品質の向上のため
  7. 対応する端末におけるアプリの障害解析およびパフォーマンス改善のため
  8. Android版における広告の表示のため
  9. お問い合わせへの対応のため
  10. 法令に基づく対応その他本サービスの適切な運営のため

第4条（利用する外部サービス）

本サービスでは、サービス提供、品質向上、広告配信その他本サービスの運営のため、以下の外部サービスを利用しています。

  1. Firebase Authentication（認証。匿名認証およびGoogleログイン）
  2. Cloud Firestore（データ保存）
  3. Cloud Functions（回答の受付、集計、通知、退会その他の処理）
  4. Firebase Cloud Messaging（プッシュ通知。Webブラウザでは利用しません）
  5. Firebase Analytics（利用状況の分析）
  6. Firebase Crashlytics（障害解析。Webブラウザでは利用しません）
  7. Firebase Performance Monitoring（パフォーマンス分析。Webブラウザでは利用しません）
  8. Google Mobile Ads（広告配信。Android版）

各外部サービスにおける情報の取扱いについては、それぞれのサービス提供者が定めるプライバシーポリシー等をご確認ください。

第5条（第三者提供）

  1. 運営者は、利用者の個人情報を第三者へ提供しません。
  2. ただし、次の各号に該当する場合は、この限りではありません。
    1. 法令に基づく場合
    2. 利用者本人の同意がある場合
    3. 本サービスの提供に必要な範囲で、Firebaseその他の外部サービス提供者へ情報を提供する場合
    4. Android版のGoogle Mobile Adsによる広告配信に必要な範囲で、広告配信事業者が情報を利用する場合
    5. 業務委託先へ必要な範囲で情報を提供する場合

第6条（情報の管理・保存）

  1. 運営者は、取得した情報について、不正アクセス、漏えい、滅失、毀損その他の事故を防止するため、適切な安全管理措置を講じます。
  2. 取得した情報は、本サービスの提供に必要な期間保存します。退会時に削除または匿名化する情報と、退会後も残す情報は、第7条のとおりです。保存期間の年数は定めていません。
  3. 情報の管理には、Firebaseその他信頼できるクラウドサービスを利用し、適切な安全管理に努めます。
  4. 運営者は、安全管理措置について、必要に応じて見直しおよび改善を行います。

第7条（アカウント削除時の取り扱い）

  1. 登録利用者が退会した場合、運営者は認証アカウントを削除し、プレイヤー名を「退会済プレイヤー」と表示します。退会には、その手続の時点で、Googleアカウントによる再確認が必要です。
  2. 回答本文、獲得ポイント、順位、ランクその他の集計結果は削除しません。
  3. プロフィールのプレイヤー名、結果が確定する前の回答に記録されたプレイヤー名、および結果に表示するプレイヤー名は、「退会済プレイヤー」へ置き換えます。結果の確定後に回答の記録へ残っているプレイヤー名は、退会処理では書き換えない場合があります。結果の画面では「退会済プレイヤー」と表示します。
  4. プッシュ通知のために保存した端末の情報は削除します。通知の履歴は、退会の手続を行った端末内からは削除します。他の端末に残っている履歴は、この処理では削除しません。
  5. お知らせの既読および通報の記録は、退会処理では削除しません。
  6. 退会後に、削除した認証アカウントおよび匿名化した表示を、退会前の状態へ戻すことはできません。

第8条（利用者の権利）

  1. 利用者は、法令の定めに従い、運営者が保有する自己の個人情報について、開示、訂正、追加、削除、利用停止等を求めることができます。
  2. 前項の請求を希望する場合は、第11条に定めるお問い合わせ先までご連絡ください。
  3. 法令により運営者が開示等の義務を負わない場合その他正当な理由がある場合には、請求に応じられないことがあります。回答本文および集計結果を退会後も残す取扱いは、第7条によります。

第9条（未成年者の利用）

未成年者が本サービスを利用する場合は、法定代理人（保護者等）の同意を得たうえで利用してください。

第10条（プライバシーポリシーの変更）

  1. 運営者は、法令の変更、本サービスの内容変更その他必要と判断した場合には、本ポリシーを変更することがあります。
  2. 本ポリシーを変更する場合、運営者は変更内容および効力発生日を、本サービス内での通知その他適切な方法により周知します。
  3. 利用者が効力発生後も本サービスを利用したときは、変更後の本ポリシーに同意したものとみなします。法令上、個別の同意が必要な変更については、その法令に従います。
