利用規約

第1条（適用）

  1. 本利用規約（以下「本規約」といいます）は、YA Labs.（以下「運営者」といいます）が提供する「IT'S正解」（正式名称「IT'S正解 - みんなの正解を予想しろ -」。以下「本サービス」といいます）の利用条件を定めます。
  2. 利用者は、本サービスを利用した時点で、本規約に同意したものとみなします。
  3. 個人情報の取扱いは、別途定めるプライバシーポリシーによります。本規約は、プライバシーポリシーに代わるものではありません。
  4. 将来、有料のプレミアムサービスを提供する場合、その料金その他の条件は第13条に従い別途表示します。プレミアムサービスについて本規約と別途表示する条件が異なるときは、別途表示する条件を優先します。

第2条（定義）

本規約で使う用語の意味は、次のとおりです。

  1. 「運営者」とは、本サービスを提供する YA Labs. をいいます。
  2. 「利用者」とは、本サービスを利用するすべての者をいいます。
  3. 「ゲスト」とは、プレイヤー名を登録せずに本サービスを利用する者をいいます。
  4. 「登録利用者」とは、Googleアカウントでログインし、プレイヤー名の登録を完了した利用者をいいます。
  5. 「お題」とは、運営者が作成し、本サービスに公開する問題をいいます。
  6. 「回答」とは、登録利用者がお題に対して投稿する文章をいいます。
  7. 「シーズン」とは、ポイントおよびランキングを集計するため、運営者が開始と終了を定める期間をいいます。
  8. 「投稿コンテンツ」とは、利用者が本サービスに投稿した回答をいいます。

第3条（規約の変更）

  1. 運営者は、法令の変更、本サービスの内容の変更その他の必要により、本規約を変更できます。
  2. 運営者は、変更後の本規約およびその効力発生日を、本サービス内での掲示その他の適切な方法で知らせます。変更が利用者に重大な影響を及ぼすときは、効力発生前に知らせるよう努めます。
  3. 法令上、個別の同意が必要な変更については、その法令に従います。
  4. 利用者が効力発生後も本サービスを利用したときは、変更後の本規約に同意したものとみなします。ただし、前項の同意が必要な場合は、この限りではありません。

第4条（アカウント）

  1. ゲストは、公開中のお題、結果およびランキングを閲覧できます。回答の投稿、回答の編集および通報は、登録利用者に限ります。
  2. ログインは、Googleアカウントにより行います。Googleアカウントの利用条件は、Googleが定めるところによります。運営者は、将来、別のログイン方法を追加する場合があります。
  3. 登録利用者は、2文字以上10文字以内のプレイヤー名を登録します。プレイヤー名は他の登録利用者と重複できません。登録後の変更はできません。
  4. 本サービスが予約している名称は、プレイヤー名に使用できません。
  5. 利用者は、自己の責任でアカウントを管理し、第三者に利用させ、譲渡し、または共有してはなりません。
  6. ログアウトしても、アカウントおよび投稿コンテンツは削除されません。ゲストとして閲覧できる状態に戻るだけです。
  7. 未成年者が本サービスを利用する場合は、法定代理人の同意を得たうえで利用するものとします。

第5条（お題および回答）

  1. お題は運営者が作成します。利用者は、お題を投稿できません。
  2. 登録利用者は、受付期間中のお題1つにつき、回答を1つ投稿できます。受付期間は、お題ごとに運営者が定めます。
  3. 回答は自由記述です。前後の空白を除いた文字数および行数は、運営者が本サービスで定める上限以内であることが必要です。空の回答、および運営者が不適切と定める表現を含む回答は投稿できません。
  4. 受付期間中、登録利用者は自己の回答を編集できます。編集回数の上限はありません。集計の対象は、受付終了時点の最終の回答です。編集すると、その回答の日時は最後に編集した日時へ更新されます。
  5. 回答を編集するときは、動画広告の視聴を求めることがあります。視聴を完了できないときは、編集できません。広告を表示できない環境では、編集できないことがあります。回答を新たに投稿すること自体には、広告の視聴を必要としません。
  6. 受付期間の終了後は、回答の投稿も編集もできません。利用者は、自己の回答だけを削除できません。
  7. 受付期間中、他の利用者の回答は表示しません。結果の公開後、同じ表記の回答をまとめて表示し、その回答をした登録利用者を表示します。

第6条（集計、ポイント、ランキングおよびランク）

  1. 結果、ポイント、順位およびランクは、運営者のサーバーで確定します。端末上の表示が、確定の直後から最新であることは保証しません。
  2. 回答は、前後の空白を除いた文字列が完全に一致するものを同じ回答としてまとめます。意味が同じでも表記が異なる回答は、別の回答です。文字の全角と半角、大文字と小文字、表記のゆれは、現在の集計では同一視しません。
  3. 本サービスは、現在、AI技術を使って回答の意味的な類似を判定しません。運営者が将来この判定を導入し、または集計方法を変更する場合は、第3条に従います。
  4. 同じ表記の回答が多い順に順位を付けます。回答数が同じグループが複数あるときは、その順位を共有し、次の順位を飛ばしません。同じ順位の登録利用者には、同じ順位のポイントを付与します。
  5. 有効な回答が5件未満のお題では、結果を表示することがあってもポイントは付与しません。5件以上のときは、1位から3位までの順位ポイント、または4位以下の参加ポイントを付与します。順位ポイントと参加ポイントは重ねて付与しません。
  6. ポイントの値は、運営者が定め、結果を確定する時点の設定を使います。確定したポイントは、その後に設定が変わっても変更しません。
  7. シーズンのランキング対象は、そのシーズンに1回以上回答した登録利用者です。一度も回答していない利用者は対象にしません。ポイントが0の参加者も対象に含みます。順位は、獲得ポイントが多い順とし、同じポイントの利用者は同じ順位とします。
  8. ランクは、そのシーズンの参加者の中での相対的な位置に基づき、S、A、B、C、DおよびEで表示します。
  9. 新しいシーズンが始まると、シーズンの累積ポイントは0から始まります。過去のシーズンの結果は閲覧できます。シーズン終了の時点で受付中のお題がある場合、運営者はその受付を終了し、そのシーズンの結果へ反映することがあります。お題を次のシーズンへ持ち越しません。
  10. ポイントおよびランクは、本サービス内の成績を示すものです。現金その他の財産と交換できません。利用者は、これらを譲渡し、売買し、または換金できません。
  11. 結果の確定後に第9条の非表示を行ったことを理由として、件数、順位、ポイントおよびランクを再計算しません。

第7条（投稿コンテンツ）

  1. 投稿コンテンツの著作権その他の権利は、投稿した利用者または正当な権利者に残ります。本条は、その権利を運営者へ譲渡するものではありません。
  2. 利用者は、運営者に対し、本サービスの提供に必要な範囲で、投稿コンテンツを無償かつ非独占的に利用する権利を許諾します。この利用には、保存、本サービス上での表示および公衆送信、集計、ランキングおよび結果への掲載、プレイヤー名と結び付けた表示、ならびに第9条および第12条の表示の変更を含みます。
  3. 前項の許諾は、利用者が退会した後も、第12条により投稿コンテンツが残る範囲で存続します。
  4. 利用者は、投稿コンテンツについて、投稿に必要な権利を自ら有し、第三者の権利を侵害しないことを表明します。
  5. 本サービスのプログラム、画面、名称、ロゴその他運営者が提供するコンテンツの権利は、運営者または正当な権利者に帰属します。利用者は、これらを本サービスの利用に必要な範囲を超えて使用できません。

第8条（禁止事項）

利用者は、次の行為をしてはなりません。

  1. 法令または公序良俗に反する行為
  2. 犯罪行為、または犯罪を助長する行為
  3. 他の利用者もしくは第三者への誹謗中傷、嫌がらせ、脅迫、差別その他これらに類する行為
  4. 他の利用者または第三者の権利を侵害する行為
  5. 個人を特定できる情報を、その人の同意なく投稿する行為
  6. わいせつ、過度に暴力的、または運営者が不適切と定める表現を投稿する行為
  7. 運営者、他の利用者または第三者になりすます行為

  12. 不適切な投稿を避けるため、文字を分割し、または置き換えて第5条の制限を回避する行為

  14. 前各号のほか、本サービスの公正な運営を妨げる行為

第9条（通報および措置）

  1. 登録利用者は、結果が公開された他の利用者の回答を、本サービスが定める次の理由で通報できます。不適切な内容、誹謗中傷・攻撃的な内容、個人情報、広告・宣伝、その他。自由な文章による通報はできません。自己の回答は通報できません。
  2. 運営者は、通報の有無にかかわらず、第8条に違反すると判断した回答について、回答の表示を「この回答は非表示です」へ置き換えること、または回答者の表示名を「非表示プレイヤー」へ置き換えることができます。回答の表示を置き換える場合、同じ表記の回答グループの表示も同様に置き換わることがあります。
  3. 前項の措置は、結果の確定後に行います。この措置を理由として、確定した件数、順位、ポイントおよびランクは再計算しません。
  4. 運営者は、すべての通報へ個別に回答する義務を負いません。措置を行う義務を、通報ごとに負うものでもありません。

第10条（広告）

  1. 本サービスは、運営者または第三者が配信する広告を表示することがあります。
  2. 広告の有無、種類、表示位置および内容は、利用する端末、ブラウザおよび本サービスの提供状況により異なります。運営者は、これらを変更できます。
  3. 第5条の回答の編集において、動画広告の視聴を求めることがあります。
  4. 本条は、広告の非表示を現に有料で提供していることを示すものではありません。広告の非表示を有料機能とする場合は、第13条によります。

第11条（通知およびお知らせ）

  1. 運営者は、お題の公開、結果の確定、シーズンの開始、自己最高ランクの更新、その他本サービスに関する事項を、本サービス内のお知らせ、または対応する端末への通知で利用者へ知らせることがあります。
  2. 対応する端末では、シーズンの開始、お題の公開、結果の確定、および自己最高ランクの更新について、通知の受け取りをそれぞれ止めることができます。Webブラウザでは、現在、これらの個別停止の設定を保存できません。
  3. 端末、ブラウザ、通信状況または外部サービスの状態により、通知が届かないことがあります。通知が届かない場合の責任は、第15条に従います。
  4. 通知の履歴は、利用中の端末内に保存されることがあります。

第12条（退会）

  1. 登録利用者は、本サービス所定の手続により退会できます。退会には、その手続の時点で、Googleアカウントによる再確認が必要です。再確認できない場合は退会できません。
  2. 退会すると、そのアカウントではログインできなくなります。プレイヤー名は「退会済プレイヤー」と表示されます。
  3. 退会後も、回答の本文、獲得ポイント、順位、ランクその他の集計結果は削除されずに残ります。結果等では、退会した利用者を「退会済プレイヤー」と表示します。
  4. 通知のために登録された端末の情報は、退会に伴い削除します。
  5. 退会後の投稿コンテンツおよび成績を、退会前の状態へ戻すことはできません。
  6. ログアウト、またはゲストとしての利用を終えるだけでは、本条の退会にはなりません。

第13条（プレミアムサービス）

  1. 本規約の制定時点では、料金の支払いを伴うプレミアムサービスは提供していません。
  2. 運営者は、将来、広告の非表示その他の追加機能を含むプレミアムサービスを提供する場合があります。
  3. 提供する場合、料金、課金の方法、利用できる期間、更新、解約、返金その他の条件は、購入の手続の前に別途表示します。未確定の条件を、本規約があらかじめ定めるものではありません。
  4. 利用者は、別途表示された条件に同意したときに、プレミアムサービスを利用できます。別途表示する条件は、プレミアムサービスに関する限り、本規約とあわせて適用されます。
  5. 運営者は、プレミアムサービスの提供を開始し、内容を変更し、または終了するにあたり、必要に応じて本規約を変更します。変更は第3条に従います。
  6. 本条は、プレミアムサービスが現に購入でき、または広告が有料で非表示になることを示すものではありません。

第14条（サービスの変更、停止および終了）

  1. 運営者は、保守、障害、法令への対応、需要、運営上の必要その他の事由により、本サービスの全部または一部を変更し、中断し、または終了できます。
  2. 運営者は、変更、中断または終了を、可能なときは事前に知らせます。緊急の場合は、事後に知らせることがあります。
  3. 本サービスを終了したときは、ポイント、ランクおよび投稿コンテンツを本サービス上で利用できなくなることがあります。
  4. 変更、中断または終了により利用者に損害が生じた場合の責任は、第15条に従います。

第15条（損害賠償）

  1. 本サービスは、他の参加者が多く選びそうな回答を予想して楽しむものです。運営者は、特定の順位、ポイント、ランク、結果、通知または広告の内容が得られることを保証しません。
  2. 運営者は、運営者の故意または重過失により利用者に損害を与えた場合、その損害を賠償します。この場合、賠償額に上限を設けません。
  3. 故意または重過失によらない事由について運営者が利用者に賠償責任を負うとき、その賠償は、当該利用者に通常生ずべき直接の損害に限られます。
  4. 将来提供する有料のプレミアムサービスについて前項の責任を負う場合、運営者の故意もしくは重過失による損害、利用者の生命もしくは身体に生じた損害、または法令上制限できない損害を除き、賠償額は、損害の原因となった事実が生じた時から遡って1か月の間に、当該利用者がそのプレミアムサービスについて運営者へ現実に支払った額を上限とします。無償で提供する機能には、この上限を適用しません。
  5. 利用者間、または利用者と第三者との間の紛争は、当事者間で解決するものとします。運営者の故意または重過失により損害が生じた場合は、第2項によります。
  6. 利用者が本規約に違反し、運営者または第三者に損害を与えた場合、利用者はその損害を賠償するものとします。

第16条（個人情報）
